    Settings

    Sign-in

    A sign-in lasts this long from the sign-in or its renewal. Opening a server with less time left than the second number asks for the password first, so a desktop is not cut off when the sign-in ends; 0 never asks. A change applies to the next sign-in; sign-ins already made keep their end.

    File transfer

    Each file sent to or fetched from a desktop, both ways; 0 is no limit. Applies from each user's next page load or sign-in.

    This proxy

    Unlock the credential store

    This database was moved here from another host. Enter the recovery passphrase to make saved credentials usable on this host.

    Reset the credential store

    When nobody has the recovery passphrase, the store can only be started over. Every saved credential and the directory service account's password are deleted; users enter their server credentials again, and the service account's password is set again below. Users, servers and assignments are kept.

    Recovery passphrase

    Encrypts exports and lets saved credentials move to a new host. Keep it with the proxy's documentation: without it an export cannot be imported. At least 12 characters.

    Export

    Downloads a zip of every user, server, assignment, saved credential and sign-in session, encrypted with the recovery passphrase.

    Frozen, the proxy keeps signing users in and carrying sessions, but refuses new saved credentials and admin changes, so nothing made after the export is lost.

    Import

    Replaces this proxy's data with an export. The current database is kept as a backup file in the data directory first.
